# DSB-SC Modulation and Demodulation Simulator

   This repository contains a MATLAB-based simulation of a Double Sideband Suppressed Carrier (DSB-SC) amplitude modulation and coherent demodulation system. 

   ## Features
   * **Signal Generation:** Creates a low-frequency sinusoidal message signal and a high-frequency carrier signal.
   * **Modulation:** Performs time-domain multiplication to suppress the carrier component.
   * **Demodulation:** Simulates coherent detection using a local oscillator and a 5th-order Butterworth Low-Pass Filter (LPF).
   * **Visualization:** Generates clear, multi-panel plots tracking the signal transformation at every stage of the communication link.

   ## How to Run
   1. Open MATLAB.
   2. Clone or download this repository.
   3. Run the `dsb_sc_simulation.m` script.
